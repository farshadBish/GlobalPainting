# Global Paint

A shared canvas: everyone who opens the page draws on the same board, live.
Front end for the [paint-mate](https://github.com/rozbh/paint-mate) server.

## Run

```sh
cp .env.example .env   # set VITE_SERVER_URL to the paint-mate address
npm install
npm run dev
```

`npm run build` · `npm run lint`
